# Tony Kasathsko

## What I do

I work in AI enablement and automation in financial services. I help teams choose between RPA and agentic AI, design the solution, and work with offshore partner teams to build and run it.

- Production document automation at a large financial services firm, using Power Automate Desktop and Cloud pipelines to handle highly variable financial documents. Processing time dropped from 3 minutes to 12 seconds per document, a 94% reduction.
- My part in governance: I meet with the business to understand the workflow, then screen each idea for RPA or agentic AI by input variability, what the output feeds, how an error spreads downstream and how errors are caught today. I write the process design, solution design document and change log, and train the business to start and stop the automation. The business signs off before go-live, monitors it daily as the first line of defense, and I handle changes when the process shifts.
