# Tony Kasathsko

I build automation that removes tedious work so people can do the work that needs them.

By day I ship production document automation at a global custody bank: Power Automate Desktop and Cloud pipelines that handle highly variable financial documents, cutting processing time from 3 minutes to 12 seconds per document.

From 4:30 to 6:00 most mornings, I build my own projects, and most of the contribution graph comes from Claude Cowork sessions. The repos are private because they run live businesses, but here's what they do:

- A children's book series my family publishes, at [maciostravels.com](https://www.maciostravels.com). The stories come from our actual family trip. I built it out in Claude Cowork: illustration prompts, book and coloring-book layouts, and the website. All 8 books (4 story books and 4 coloring and activity books) are live on Amazon KDP in English and Portuguese. A Grok Bot agent writes and posts the series' social content, and it runs the Pinterest account, where monthly views went from 100K to 900K+ in 2 months.
- [PastInMini](https://www.youtube.com/@pastinmini), a short-form history channel. One n8n workflow chains four AI models per video; Creatomate assembles each video and Blotato publishes it to five platforms. It has run hands-off since June 2025, and a Grok Bot agent now runs on top of it, pulling analytics across all five platforms and optimizing for engagement.
- A fleet of Grok Bot agents that run these processes on custom skill files I write. These same processes previously ran on OpenClaw, a multi-agent framework with OpenRouter access to route tasks across different LLMs, before I migrated them to Grok.
